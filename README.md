# Neurônios — Sistema Nervoso

Site educativo sobre neurônios, com página da maquete (galeria + carrossel) e página da equipe.
Projeto das alunas Luiza Nóbrega, Rebeka Gracielly e Sarah Beatriz — 1º Informática.

## Como executar

Não precisa instalar nada nem usar servidor: basta abrir o arquivo **`index.html`** com um
clique duplo (qualquer navegador moderno, em Windows, macOS ou Linux). Todos os caminhos são
relativos, então a pasta pode ficar em qualquer lugar do computador.

## Estrutura de pastas

```
c-lula-neur-nio/
├── index.html          # página inicial
├── maquete.html        # construção da maquete (galeria + carrossel)
├── equipe.html         # integrantes do grupo
├── css/
│   ├── base.css        # variáveis, reset, cabeçalho, menu, botões, rodapé
│   ├── home.css        # estilos da página inicial
│   ├── paginas.css     # estilos de maquete.html e equipe.html
│   └── carrossel.css   # estilos do carrossel
├── js/
│   └── carrossel.js    # lógica do carrossel
└── img/
    ├── home/           # ilustrações da página inicial
    └── maquete/
        ├── galeria/    # fotos das etapas (etapa-1 a etapa-6)
        └── carrossel/  # fotos da maquete pronta (maquete-1 a maquete-4)
```
